## 3) التوقيع والبناء

| البند | التفاصيل |
|---|---|
| مخزن المفاتيح | `android/app/nexora-release.jks` (alias `nexora`) — شهادة عائلة ثابتة `ae74add0…fa6b` |
| التوقيع | apksigner — مخططات v1 (JAR) + v2 + v3 |
| المعماريات المستهدفة | `arm64-v8a` + `armeabi-v7a` (Universal يجمعهما بمجموعات مكتبات منقّاة لكل ABI) |
| x86_64/x86 | NOT PROVIDED — لا فائدة عملية للهواتف (المحاكيات فقط) |
| البناء الآلي | GitHub Actions: analyze + test + build APK + release عند كل push |
| قاعدة versionCode الموثقة | مع `--split-per-abi` تُضاف إزاحة ABI فوق رقم البناء الممرّر؛ بدونها (fat) يُستخدم الرقم حرفياً — v0.1.0 يبدأ من `0.1.0+1` |

### دروس تقنية موثقة (كود المستقبل)
1. **مجموعات ABI الجزئية من Gradle**: بدون `abiFilters` تُغلَّف مكتبات JNI لكل المعماريات داخل AARs حتى مع `--target-platform` واحد — جهاز arm64 قد يجد `lib/arm64-v8a/` ناقصة `libflutter` → تثبيت ناجح ثم انهيار عند الإقلاع. العلاج: مخرجات منقّاة لكل ABI، وUniversal بمجموعات كاملة من مصدر موثق واحد.
2. **تنظيف `libflutter.so` لقناة v7a**: `objcopy --strip-unneeded` يُنزّل المكتبة من ~133MB إلى ~7.9MB دون مساس بلقطة Dart AOT (`libapp.so`).
3. **الدمج على مستوى ZIP** (`scripts/v010_universal_build.py`) يسمح بإنتاج Universal من بناء واحد على أقراص ضيقة، ثم `zipalign -p 4` → `apksigner` → verify.
