# CHANGELOG

## v0.1.0 — النسخة التجريبية الأولى (أكتوبر 2026)

> أول إصدار تجريبي عام. يجمع كل التطوير الداخلي السابق في نسخة واحدة
> موقّعة رسمياً، وتُعد نقطة البداية المعتمدة لترقيم الإصدارات.

### الميزات الخمس الجديدة
1. **الرسائل المؤقتة** (Disappearing messages): TTL لكل محادثة
   (24 ساعة / 7 أيام / 90 يوماً) — يُفرض من الخادم عبر `expires_at`
   (زناد + تنظيف دوري RPC) مع حذف محلي متزامن.
2. **الرسائل المحفوظة** (Starred messages): جدول `message_stars`
   بسياسات RLS، شاشة «الرسائل المحفوظة» عبر كل المحادثات، وعلامة
   ⭐ على فقاعة الرسالة.
3. **السحب للرد** (Swipe-to-reply): بنمط واتساب، آمن للاتجاه RTL،
   مع عتبة إيماءة قابلة للاختبار.
4. **تصدير المحادثة**: نسخ النص المحفوظ محلياً كملف `.txt` عبر
   مشاركة النظام — بدون خروج أي بيانات غير مشفرة عن الجهاز.
5. **معرض وسائط المحادثة**: كل الوسائط المخزّنة مؤقتاً في شبكة
   واحدة، فتح وتنزيل وإعادة توجيه.

### البناء والنشر
- بناء متعدد المعماريات: Universal (arm64 + ARMv7) + v7a، مجموعات
  مكتبات أصلية منقّاة لكل ABI، وتوقيع رسمي (v2+v3).
- ترقيع قاعدة البيانات `2026-10-08-v010-disappearing-stars.sql`
  مطبَّق ومُدقق (7/7 PASS)؛ `supabase/schema.sql` محدّث كمرجع أساسي.
- الاختبارات 59/59 ناجحة، `flutter analyze` نظيف.

## سجل التطوير الداخلي (مُضمَّن بالكامل في v0.1.0)

> كل ما يلي طُوِّر وصُحِّح خلال الدورات الداخلية التي سبقت أول إصدار
> تجريبي عام، وهو جزء من كود v0.1.0. التفاصيل الكاملة في تاريخ Git.

- **إعادة الهندسة الكاملة**: معمارية طبقية (core/crypto/data/services/state/features)،
  بروتوكول X3DH + Double Ratchet، مجموعات بمفاتيح متناوبة، أوفلاين ومزامنة،
  اختبارات آلية وبناء APK عبر CI.
- **الخصوصية والحضور**: حضور «متصل الآن» مفروض من الخادم، إيصالات قراءة
  اختيارية (read_marks)، إغلاق سباق OPK ذرياً (`SKIP LOCKED`).
- **الإشعارات**: إشعارات محلية عند فتح/خلفية التطبيق + تكامل عميل FCM
  جاهز (يحتاج خطوتي المالك للتفعيل النظامي).
- **المكالمات**: WebRTC ثنائية صوت/فيديو + هيكل مجموعات (flag مغلق).
- **الملف الشخصي الكامل**: صورة شخصية مع قص وتصغير ورفع بحاوية RLS،
  تعديل اسم المستخدم، تغيير البريد وكلمة المرور.
- **البريد الإلكتروني**: قوالب تأكيد/استعادة/دعوة/تغيير بريد + موقع تحقق
  مستضاف (بانتظار لصقها في لوحة Supabase من المالك).
- **التجديد البصري**: أيقونة جديدة، حركة واتساق، إصلاحات وضع فاتح حقيقية.
- **إصلاحات حرجة ميدانياً**: شاشة الدخول الرمادية، تعليق الإقلاع،
  «الحزمة غير صالحة»، انهيار RangeError عند أول إقلاع، شريط الإدخال
  السفلي، قفزات سجل المحادثة، فشل فتح المحادثة (فهرس جزئي)، تسجيل
  الحسابات الجديدة.
- **أمان التوزيع**: توقيع إصدار ثابت `nexora-release.jks`، بناء متعدد
  المعماريات بمكتبات منقّاة، ودليل تثبيت بخمس خطوات.
