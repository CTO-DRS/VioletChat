# TESTING — DRS NEXORA

## ما يُشغَّل في CI (على كل push)
`flutter test` — يشمل:

### test/crypto_test.dart (21 حالة اختبار)
- **Primitives**: AES-GCM دورة كاملة + رفض العبث، HKDF تحديدية وحساسة
  للملح، توافق سر X25519، توقيع/تحقق Ed25519.
- **X3DH + Double Ratchet (محاكاة طرفين)**:
  - تأسيس جلسة + تبادل ثنائي الاتجاه مع دندنة DH.
  - **Forward secrecy**: نص قديم يفشل بعد تقدم السلاسل.
  - **حماية الإعادة**: فك مكرر يفشل.
  - **خارج الترتيب**: تسليم 2 ثم 1 ينجح.
  - **حفظ/استعادة الجلسة**: استئناف بعد تسلسل/فك تشفير صحيح.
- **GroupKeys**: تغليف/فتح للعضو الصحيح، **فشل الغريب**، عزل مفاتيح
  الرسائل بين المحادثات والإصدارات.
- **SafetyNumber**: تناظر، 12 مجموعة، حساسية للمفاتيح.
- **Message envelope (مضمّن)**: FULL WIRE PATH (Ratchet → غلاف →
  jsonEncode → توجيه → فك — يعيد إنتاج مسار الخادم بالضبط)، توجيه
  أغلفة الأجهزة، إصدار مفتاح المجموعة عبر JSON، عزل مفاتيح الوسائط،
  رسائل النظام.
- **آلة حالات الرسالة**: عقد queued→sending→sent→delivered→read/failed.

### test/settings_test.dart (جديد)
- افتراضيات الخصوصية: showPresence/readReceipts مفعّلة.
- جولة JSON تحفظ المفتاحين الجديدين.
- **توافق رجعي**: إعدادات محفوظة من بناء سابق (بلا show_presence) لا تفشل
  وتُفسَّر بالمفتاح الافتراضي.
- عقد ICE الافتراضي: بلا dart-defines → STUN فقط وturnConfigured=false.
